# Rakshith Raghavendra — Dark Engineering Laboratory & Portfolio

An ultra-premium, dark engineering laboratory-themed editorial portfolio website for **Rakshith Raghavendra**, CSE–AI/ML student and engineering project builder.

Designed with an aesthetic identity of:
> **Dark Engineering Laboratory × Editorial Design × Premium Technology Product × Interactive Digital Archive**

---

## 🛠️ Stack Constraints

This project is built using strictly **Vanilla Standards**:
- **HTML5** (Semantic structure, ARIA accessibility attributes, modal accessibility)
- **CSS3** (CSS Variables, Flexbox, CSS Grid, custom transforms, backdrop filters, animation keyframes)
- **Vanilla JavaScript (ES6+)** (Canvas background renderer, precision dual cursor, magnetic button physics, dynamic modal system, timeline accordions, scroll observers, real-time live clock)

No external libraries (No React, Vue, Angular, Tailwind, Bootstrap, Three.js, GSAP, or third-party UI components).

## 🚀 How to Run Locally

Since this application relies entirely on web-standard HTML5, CSS3, and JavaScript, you can view it directly by either:

1. **Direct Browser Launch**:
   Double click `index.html` or open `index.html` in any web browser.

2. **Local HTTP Server (Recommended)**:
   Run a local dev server using Node/npx or Python:
   ```bash
   # Using npx serve
   npx -y serve .

   # OR using Python
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.

## 🧪 Included Technical Case Studies

1. **AGROSORT AI**: IoT + AI robotic fruit sorting system using ESP32, 4-DOF mechanical arm, and lightweight CNN edge vision.
2. **HARDWARELAB OS**: Engineering workspace and evidence memory system for firmware iterations, logic analyzer captures, and post-mortems.
3. **FIBER GRATING + ML**: Machine-learning-based signal processing pipeline for Fiber Bragg Grating optical sensor decoupling.
4. **EMBEDDED SYSTEMS LAB**: Headless Raspberry Pi 4 cluster and Linux server infrastructure configured for continuous integration, hardware testing, and VPN tunneling.
